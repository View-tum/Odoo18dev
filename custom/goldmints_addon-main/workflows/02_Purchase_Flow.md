# 🛒 02. Purchase Flow (ระบบจัดซื้อและการคุมงบ)

ส่วนนี้อธิบายการจัดการสั่งวัสดุ (เช่น หลอดพลาสติก, ฝา, น้ำยา Menthol) ให้ตรงกับยอดที่ขาดหน้างาน

---

## 🔄 Workflow รายละเอียดเครื่องมือ

### 📌 ขั้นตอนที่ 1: ตรวจสอบวัลดุขาดหน้าตัก (Automatic Checks)
*   **เครื่องมือ**: MPS หรือความต้องการหน้าเครนระบบจะสั่งมองวัตถุดิบ
*   หากคลังตัดเบิกแล้วไม่สามารถให้ผลิตต่อได้ -> **สร้างใบขอซื้อ (Purchase Request - PR)**

### 📌 ขั้นตอนที่ 2: อนุมัติแบบหลายระดับคุม Budget (Multi-Level Approval)
*   **Customization ที่ใช้อยู่ (`purchase_request`, `oi_workflow_purchase_request`)**:
    *   ผู้ขอ (เช่น หัวหน้าฝ่ายผลิต) สั่งสร้าง PR
    *   ระบบเด้งแจ้งเตือนเข้าแอป/หลังบ้านให้ผู้มีอำนาจ (เช่น ผู้จัดการ -> ฝ่ายบริหาร) กด Approve
    *   หากมีงบเกินดุล `budget_control_purchase_request` จะประมวลประเมินสัดส่วนงบทันทีป้องกันงบบานปลาย

### 📌 ขั้นตอนที่ 3: เปิด PO สั่งสินค้า (Verify with Supplier)
*   **เครื่องมือ**: อนุมัติ PR เรียบร้อย เปลี่ยนร่างเป็น **Purchase Order (PO)**
*   ส่ง PO ให้ Supplier ผ่านอีเมล
*   `purchase_price_history`: คอยเช็คประวัติราคาเดิม ไม่ให้ซัพพลายเออร์ตั้งเบ่งราคาฟันกำไร

## 💡 สิ่งสำคัญใน Module นี้
*   **การยืนยันงบ**: ควบคู่กับบัญชีลดภาวะลืมคีย์ยอดจัดสรรที่ซ้ำซ้อน
*   **การติดตามปลายทาง**: `po_purchase_request_smart_button` กดสปอตดูได้ทันทีว่า PO ใบนี้ เปิดมาเพื่อสั่งทำเซตอะไรในใบงานไหน
