# 🛒 02. เจาะลึกฟังก์ชันระบบจัดซื้อและคลังสินค้า (Purchase & Inventory)

ส่วนนี้อธิบายการทำงานแบบคลิกต่อคลิกของระบบฝ่ายจัดซื้อ และการกระจายวัสดุสู่หน้ากากผลิต

---

## 🔍 A. ฟังก์ชันหน้าจอฝ่ายจัดซื้อ (Purchase Detail)

### **1. ฟังก์ชันเปิดใบขอซื้อ (Purchase Request - PR)**
*   **เมื่อเกิดเงื่อนไข**: หน้าเครื่อง MPS แจ้งยอดขาดวัสดุ หรือหัวหน้างานเบิกของเกินพิกัด
*   **คลิกใช้งาน (`purchase_request`)**:
    *   ผู้ใช้สร้างใบ PR -> ระบุชื่อสินค้า (เช่น หลอดพลาสติก), จำนวนที่ขอ, และแผนก/โปรเจกต์
    *   **สิ่งเพิ่มเข้ามา (`oi_workflow_purchase_request`)**:
        *   เมื่อกด `Submit` -> ระบบวิ่งเข้า **สายอนุมัติ (Workflow Approval)** อัตโนมัติค้างหน้าจอให้ผู้บริหารตรวจสอบ
        *   ฟังก์ชัน `budget_control`: จะตรวจสอบยอดงบรายเดือนของฝ่ายผลิตทันที หากยอด PR ทะลุงบที่ตั้งไว้ ระบบจะแสร้ง Error ป้องกันการเซ็นแบบสุ่มเดาสุ่มสี่สุ่มห้า

### **2. ฟังก์ชันแปลงใบ PR เป็นใบสั่งซื้อ (Convert PR to PO)**
*   เมื่อผู้ใหญ่ Approve PR เรียบร้อย -> เจ้าหน้าที่จัดซื้อจะคลิกกดปุ่ม **`Create RFQ / PO`** (แปลงร่าง)
*   ระบบจะดึงราคาเดิมจาก `purchase_price_history` มาแสดงดักพฤติกรรม เพื่อให้เจ้าหน้าที่ตรวจสอบว่าถูกหรือแพงกว่าปีที่แล้วก่อนส่งให้อธิบดีสรุป

---

## 🔍 B. ฟังก์ชันหน้าจอคลังสินค้า (Inventory Detail)

เมื่อจัดซื้อสั่งของ Supplier วิ่งรถมาส่ง ยอดจะไหลเข้า Inventory:

### **1. ฟังก์ชันรับของเข้าคลัง (Receipt / Checking Lot)**
*   **เมื่อคลิกใช้งาน**: ผู้ใช้ประทับตรากดปุ่ม `Validate` ใบรับของ
*   **สิ่งเพิ่มเข้ามา (`nano_transfer_product_lot`)**:
        *   Odoo จะบังคับให้คีย์เบอร์ล็อต (Lot Number) และรอบวันหมดอายุ / วันผลิต
        *   ยอด On-hand ในระบบคลังใหญ่ (Main Store) จะพุ่งพรวดขึ้นมาแบบสถารปนาพร้อมเบิกจอง

### **2. ฟังก์ชันย้ายของเตรียมเบิกผลิต (Internal Transfer - Feed to WC)**
*   **ฟังก์ชัน**: สร้างใบ **Internal Transfer (ใบโอนย้าย)** 
*   **ขั้นตอน**:
    1.  ย้ายวัสดุจาก `WH/Stock` (คลังใหญ่) ไหลเข้า `WH/Pre-Production` (คลังหน้างาน)
    2.  ระบบมี `stock_no_negative` ดักไว้: **ห้ามคีย์ย้ายของที่ยอดติดลบ หรือตัดของออกจากคลังมั่วโดยไม่มีเอกสาร MO รับรอง**

### **3. ฟังก์ชันเตรียมกระจายรถ (Delivery Routes)**
*   **ฟังก์ชัน**: จัดเส้นทางกระจายส่งยาดม
*   **ขั้นตอน**:
    1.  พนักงานเปิดคิว **Delivery Order** หลายใบที่อนุมัติแล้ว
    2.  คลิกกดกรุ๊ปทำ **Delivery Route Layout** สรุปเส้นทางยาดมพ่วงรถ
    3.  พิมพ์ใบตรวจสอบรายการของขึ้นรถ เพื่อให้ Logistics แพ็คของขึ้นตู้ปัดสต๊อกสะสมออกไปสู่หน้าห้าง

---
