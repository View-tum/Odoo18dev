# 🧠 00. แกนกลางโลจิสติกดง Odoo (MTS, MTO & การจองสินค้า)

ทำความเข้าใจกลไกลพื้นฐานของ Odoo 18 ที่คุมระบบคลังสินค้าและการผลิต ก่อนที่จะทำความเข้าใจในแต่ละฟังก์ชัน Custom

---

## 📌 1. ความแตกต่างระหว่าง MTO และ MTS

สำหรับการผลิตยาดมหรือชิ้นส่วนพลาสติก Odoo สามารถคุมทิศทางได้ 2 รูปแบบหลักๆ:

![MTS vs MTO Flow](../images/02_MTS_MTO_Flow.png)

### 🔵 **A. MTO (Make-To-Order) - ผลิตเมื่อมีออเดอร์**
*   **นิยาม**: ระบบจะเปิดคำสั่งผลิต (MO) หรือคำสั่งซื้อ (PO) สั่งตรงจากใบสั่งขาย (SO) รายใบทันที โดย**ไม่สนใจสต๊อกที่มีอยู่**
*   **เมื่อไหร่ที่ใช้**: ยาดมล็อตส่งออกพิเศษ หรือพลาสติกสีที่ไม่ได้ทำสต๊อก คัสตอมตามใจลูกค้าคันเดียว
*   **ฟังก์ชันการทำงาน**:
    1.  เซลล์คีย์ Sale Order ยาดมสีทอง 10,000 ชิ้น
    2.  ระบบเชื่อม Route: **`Replenish on Order (MTO)`**
    3.  เมื่อ Confirm SO -> ระบบจะดีดใบสร้าง Manufacturing Order (MO) สีทองทับคิวทันที ยอดเป๊ะตามหน้าบิล

---

### 🟢 **B. MTS (Make-To-Stock) - ผลิตเพื่อตีสต๊อก (ระบบปัจจุบัน)**
*   **นิยาม**: ผลิตตามเป้าหมายคลังเฉลี่ย พยากรณ์ และจัดสรร (การผลิตรายสัปดาห์ / รายวัน)
*   **เมื่อไหร่ที่ใช้**: ยาดมตัวมาตรฐาน (Core Product) ที่ต้องมีสต๊อกค้างกะตลอด
*   **ฟังก์ชันการทำงาน**:
    1.  ฝ่ายวางแผนดูหน้า **MPS (Master Production Schedule)**
    2.  กรอกยอด Forecasting เช่น "สัปดาห์นี้ควรมีพลาสติกฉีด 50,000 ชิ้น"
    3.  คลิก **`Replenish`** -> ระบบจะเช็คว่า: `จำนวนที่ต้องมี - จำนวนสต๊อกจริง = ยอดที่ขาด` 
    4.  สร้างคำสั่งดักตัด MO/PR ตามยอดปัดเศษอัตโนมัติ

---

## 📌 2. กลไกการจองสินค้า (Component Reservation)

หน้าจอ MO จะบอกว่าของ "พร้อมประกอบ" หรือไม่ ดูจากจุดนี้:

![Stock Reservation Diagram](../images/03_Stock_Reservation.png)

### 🔍 **A. ความเข้าใจเรื่องตัวเลขสต๊อก**
*   **On-Hand (จำนวนที่มีจริง)**: นับได้เลยในหลอดแก้ว
*   **Reserved (จำนวนที่ถูกจอง)**: ของยังอยู่บนชั้นวาง แต่เป็นของ MO/SO ใบอื่นไปแล้ว ห้ามหยิบ!
*   **Available / Free (จำนวนที่พร้อมใช้)**: `On-hand` - `Reserved`

### 🔍 **B. สเต็ปเวลาเปิดใบผลิต (MO)**
1.  **Draft (ร่าง)**: ระบบคำนวณจากสูตร BOM ว่าต้องใช้ ฝา 10 ชิ้น, น้ำมัน 1 ลิตร
2.  **Confirmed (ยืนยันเปิดใบ)**:
    *   ระบบกดรันฟังก์ชัน **`Check Availability`** (ตรวจสต๊อก)
    *   **กรณีที่ 1 (ของครบสีเขียว)**: ยอด Reserved ในคลังจะเพิ่มขึ้น ทับยอด Available ทันที พนักงานลุยงานได้
    *   **กรณีที่ 2 (ของขาดสีแดง)**: MO จะขึ้นสถานะ `Waiting for Components` (รอวัตถุดิบ) หรือ `Partially Available` (ขาดบางตัว)
3.  **การเติมของอัตโนมัติ (Replenishment)**:
    *   เมื่อของสถานะเป็นสีแดง Odoo จะเช็ค Rule ระบบจัดซื้ออัตโนมัติ (Reordering Rules) เพื่อสั่ง PR สั่งเพิ่ม ดึงความสามารถเบิกจ่ายมาให้ MO อัตโนมัติ

---

## 📌 3. การใช้ BOM (Bill of Materials) และ Operation

*   **BOM (สูตรโครงสร้างสินค้า)**:
    *   ยาดม 1 หลอด = [ฝาบน 1] + [ตัวกลาง 1] + [สำลีชุบ 1] + [น้ำมันผสม 5ml]
*   **Operations (ขั้นตอนการประกอบ)**:
    *   **Step 1 : ฉีดเป่าพลาสติก** (ใช้เครื่อง Injection)
    *   **Step 2 : ประกอบสำลี** (ใช้คน / Robot)
    *   **Step 3 : แพ็คลงกล่อง** (ใช้เครื่อง Wrapper)
*   *เมื่อพนักงานทำผ่าน Console* -> ระบบจะเช็ค Consumption ตัดวัสดุ (Backflush หรือ Manual) รายช็อตดักยอดที่คีย์ Done รายคาบนั่นเอง
