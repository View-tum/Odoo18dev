# 📑 01. เจาะลึกฟังก์ชันระบบงานขาย (Sales Detail)

ส่วนนี้จะอธิบายคลิกทุกปุ่ม (Functions) ในหน้าระบบงานขายแบบละเอียด ทั้ง Standard และ Custom

---

## 🔍 A. ฟังก์ชันหน้าจอเอกสารใบสั่งขาย (Sale order - SO)

### **1. ฟังก์ชันนำเข้าออเดอร์ (Import Sales - Custom)**
*   **เมื่อคลิกใช้งาน**: ผู้ใช้กดปุ่ม `Import Goldmints Orders` -> แนบไฟล์ Excel จากฝั่งลูกค้า/ห้าง
*   **สิ่งที่ระบบทำเบื้องหลัง**:
    *   แมปชื่อลูกค้า (Partner Name) และรหัสสาขาให้ตรงกับฐานข้อมูล
    *   แมปรหัสสินค้า (Product SKU) เพื่อดึงราคาขาย (Pricelist) อัตโนมัติแบบพวงเซต
    *   สร้างใบ SO สถานะ **`Draft` (ร่าง)** ค้างไว้หลายๆ ใบทีเดียวเพื่อรอกดตรวจสอบความถูกต้อง

---

### **2. ฟังก์ชันตรวจสอบเครดิต (Credit Limit Check - Custom)**
*   **เมื่อคลิกฟังก์ชัน `Confirm` (ยืนยัน)**:
    *   มาตรฐาน Odoo (Standard) จะเปลี่ยน SO เป็นสถานะ `Sale Order` และสร้างใบส่งของ (Delivery Order) ทันที
    *   **สิ่งเพิ่มเข้ามา (`sale_credit_limit_warning`)**:
        *   ระบบจะวิ่งไปบวกเลข ยอดขายค้างทับส่งมอบก้อนโต + ยอดเงินตัดรอบบัญชี (Account Receivable)
        *   หากเกินลิมิตในข้อมูลรายชื่อคู่ค้า -> **ดีด Error ป๊อบอัพสีแดง** ล็อคไม่ให้เซลส์กด `Confirm` สำเร็จ
    *   **การปลดล็อค (Approval)**: ต้องให้ผู้จัดการหรือบัญชี ตรวจสอบและกดเครื่องหมาย "Approve Limit Over" เพื่อเซฟผ่านสิทธิพิเศษ

---

### **3. ฟังก์ชันการคุมราคาเซลส์ (Pricelist Guard)**
*   **ฟังก์ชัน**: `sale_customer_pricelist_percent_limit` ตัวคุมค่าตัดส่วนลด
*   **เมื่อคีย์ยอด**: หากเซลล์คีย์ส่วนลด เกิน % ที่ตั้งค่าคุมไว้ตามระดับขั้นของ Pricelist (เช่น ห้ามลดเกิน 10% ของราคาทุนบวกลบ)
*   **ผลลัพธ์**: ระบบจะเด้ง Notification เตือน หรือล็อคปุ่มยืนยัน ป้องกันการป้อนตัวเลขผิดพลาด (Human Error) ที่ทำให้บริษัทขาดทุน

---

## 🔍 B. การไหลเวียนของข้อมูลจาก SO

เมื่อ SO เปลี่ยนสถานะเป็น **`Sale Order`** ระบบจะเปิดการใช้งานอีก 2 ฟังก์ชันโดยอัตโนมัติ (Automated Trigger):

1.  **สร้างความต้องการในคลัง (DO Trigger)**:
    *   ระบบสร้างเอกสาร **Delivery Order (ใบส่งของ)** สถานะ `Waiting` (รอของ) หรือ `Ready` (พร้อมส่ง)
2.  **ดึงยอดพยากรณ์เข้าส่วนกลาง**:
    *   ใบ SO ก้อนนี้จะพุ่งยอดเข้าไปหาใบตารางรวม **MPS** เพื่อดึงยอดจัดสรรสั่งขยายปริมาตรในสัปดาห์ปัจจุบัน

---
