# 📑 01. Sales Flow (ระบบงานขายและการประมวลรายได้)

ส่วนนี้อธิบายการจัดการ "ยอดสั่งซื้อ" และ "ตัวคุมวงเงินหนี้เน่า" ก่อนส่งเข้าสู่การผลิต

---

## 🔄 Workflow รายละเอียดเครื่องมือ

### 📌 ขั้นตอนที่ 1: การป้อนคำสั่งซื้อ (Order Input)
*   **Standard Odoo**: สร้างใบสั่งขาย (Sale order - SO) รายใบ
*   **Customization ที่ใช้อยู่ (`sale_order_import_goldmints`)**:
    *   ดึงออเดอร์จากระบบภายนอก (เช่น Excel ห้าง/แพลตฟอร์ม) เข้ามา Batch Create หลายๆ ใบพร้อมกันเพื่อประหยัดสปีด

### 📌 ขั้นตอนที่ 2: ระบบคัดกรองความปลอดภัยทรัพย์สิน (Credit Verification)
*   **ปัญหาหน้างาน**: หากลูกค้าติดค้างหนี้เยอะ เซลจะห้ามปล่อยของ
*   **Customization ที่ใช้อยู่ (`sale_credit_limit_warning`, `partner_credit_limit_sale_block`)**:
    *   เมื่อกด Confirm SO ระบบจะเช็คเครดิต **Account Receivable** สะสม
    *   หาก "เกินเพดาน" -> ระบบจะเด้งแจ้งเตือน หรือ Block Lock ไม่ให้กดสร้าง Invoice/Delivery จนกว่าหัวหน้าจะ Approve ปลดล็อค

### 📌 ขั้นตอนที่ 3: ปล่อยยอดเข้าการผลิต (Production Trigger)
*   เมื่อไฟเขียวผ่าน SO จะถูกยืนยัน (Confirmed)
*   ยอดส่งมอบจะถูกผูกเข้าเส้นรอบการจัดสรรของ **MPS (Master Production Schedule)** เพื่อจัดตารางว่า "วันนี้ต้องได้ยาดมเท่าไหร่ เพื่อปล่อยรถส่ง"

---

## 💡 สิ่งสำคัญใน Module นี้
*   **ไม่มีแรงกดดันที่เป้า MO**: เพราะระบบจะกรอง SO รายช็อตไปรอปั่นยอดในคลังสัปดาห์
*   **การจัดการราคา**: มี `sale_customer_pricelist_percent_limit` คอยคุมกรอบราคาขายไม่ให้เซลกดส่วนลดพ่วงผิดพลาด
