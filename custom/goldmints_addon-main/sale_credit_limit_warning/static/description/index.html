Sale Credit Limit Warning

This module extends Sales credit warning to show customer-level and company-group-level credit exposure directly on quotations.

What It Calculates

  • Credit Limit
  • Credit Used (Invoiced)
  • Credit Used (SO Approved)
  • Credit Balance = Credit Limit - Invoiced - SO Approved

Alert Rule

An alert is shown when: Credit Balance - Current SO < 0 for either the customer or the company group.

User Action

A Check Credit button is added on quotation form (Draft / Sent) to force display of the credit banner details.

Dependencies

  • sale
  • company_group_structure
