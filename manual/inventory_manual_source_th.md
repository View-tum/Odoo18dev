## 1. Introduction

### 1.1 ภาพรวมของระบบ (IV-01)

เส้นทางเข้าเมนู: หน้า App Switcher ของ Odoo

หน้าจอนี้เป็นจุดเริ่มต้นของผู้ใช้งานก่อนเข้าโมดูล Inventory และโมดูลที่เกี่ยวข้อง เช่น Purchase, Manufacturing และ Accounting ซึ่งมีผลต่อข้อมูลสต็อกเดียวกัน

![รูปที่ 1.1 หน้ารวมแอปของระบบ Odoo](iv01_home.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| Inventory | ไอคอนสำหรับเข้าโมดูลคลังสินค้า | ได้ | เปิดหน้า Inventory Overview |
| Purchase | ไอคอนสำหรับเข้างานจัดซื้อ | ได้ | ใช้ต่อยอดงาน RFQ/PO ที่เกิดจากการเติมสต็อก |
| Manufacturing | ไอคอนสำหรับเข้างานผลิต | ได้ | ใช้ดูงาน MO และสต็อกที่เกี่ยวกับการผลิต |
| Accounting | ไอคอนสำหรับเข้างานบัญชี | ได้ | ใช้ติดตามมูลค่าสต็อกและรายงานการเงิน |
| แถบแจ้งเตือนด้านขวาบน | แสดง message, activity และข้อมูลผู้ใช้ | ได้ | ใช้ดูงานค้างและเข้าเมนูตั้งค่าผู้ใช้ |
| User Menu | เมนูผู้ใช้มุมขวาบน | ได้ | ใช้เข้า My Profile, Preferences และออกจากระบบ |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| คลิก Inventory | Inventory Overview | เข้าสู่หน้าหลักของงานคลังสินค้า |
| คลิก Purchase | Purchase Dashboard | เข้าสู่โมดูลจัดซื้อเพื่อติดตาม RFQ/PO |
| คลิก User Menu | เมนูผู้ใช้ | เลือก My Profile, Preferences หรือ Log out ได้ |

### 1.2 การเข้าสู่ระบบ (IV-02)

เส้นทางเข้าเมนู: หน้าเข้าสู่ระบบ Odoo

ผู้ใช้งานต้องกรอกข้อมูลสำหรับยืนยันตัวตนก่อนเข้าระบบ โดยสิทธิ์ที่ได้รับจะมีผลต่อเมนูและข้อมูลที่มองเห็นภายใน Inventory

![รูปที่ 1.2 หน้าจอเข้าสู่ระบบ](iv02_login.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| Database | ชื่อฐานข้อมูลที่ใช้งาน | ได้ | กำหนดว่าผู้ใช้จะเข้าสู่ข้อมูลชุดใด |
| Email / Login | ชื่อผู้ใช้สำหรับเข้าสู่ระบบ | ได้ | ระบบใช้ตรวจสอบตัวตนของผู้ใช้งาน |
| Password | รหัสผ่านของผู้ใช้งาน | ได้ | ระบบใช้ยืนยันตัวตนร่วมกับชื่อผู้ใช้ |
| Log in | ปุ่มเข้าสู่ระบบ | ได้ | ส่งข้อมูลเพื่อเข้าใช้งานระบบ |
| Reset Password / Forgot Password | ลิงก์สำหรับตั้งรหัสผ่านใหม่ | ได้ | ระบบพาไปขั้นตอนขอเปลี่ยนรหัสผ่าน |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| กรอก Email และ Password | หน้าเดิม | เตรียมข้อมูลสำหรับยืนยันตัวตน |
| คลิก Log in | หน้าแรกของระบบตามสิทธิ์ | หากข้อมูลถูกต้อง ระบบจะพาเข้าสู่ Odoo |
| คลิก Reset Password | หน้ารีเซ็ตรหัสผ่าน | ใช้ขอเปลี่ยนรหัสผ่านใหม่ |

### 1.3 หน้าหลักของระบบ (IV-03)

เส้นทางเข้าเมนู: Inventory > Overview

Inventory Overview เป็นหน้า dashboard สรุปจำนวนงานตามประเภทการเคลื่อนไหว เช่น รับสินค้า, หยิบสินค้า, โอนย้าย และจัดส่ง ผู้ใช้ใช้หน้านี้เพื่อตรวจงานและเจาะเข้า operation ที่ต้องทำต่อ

![รูปที่ 1.3 หน้าหลัก Inventory Overview](iv03_inventory_overview.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| Receipts | การ์ดสรุปงานรับสินค้าเข้า | ได้ | กดเพื่อเปิดรายการ Receipt ที่รอทำ |
| Internal Transfers | การ์ดสรุปงานโอนย้ายภายใน | ได้ | กดเพื่อเปิดรายการโอนย้ายภายใน |
| Pick | การ์ดสรุปงานหยิบสินค้า | ได้ | กดเพื่อเปิดงานหยิบสินค้าที่รอทำ |
| Delivery Orders | การ์ดสรุปงานจัดส่ง | ได้ | กดเพื่อเปิดรายการ Delivery |
| จำนวนงานบนการ์ด | แสดงปริมาณงานคงค้างในแต่ละประเภท | ไม่ได้ | ใช้ติดตามภาพรวมงานคงค้างแบบ real-time |
| ปุ่ม Open / To Process | ปุ่มลัดเข้ารายการตามสถานะงาน | ได้ | เปิดรายการที่ตรงกับประเภทและสถานะบนการ์ด |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| คลิกการ์ด Receipts | หน้ารายการ Receipts | ดูเอกสารรับสินค้าและกดตรวจรับต่อได้ |
| คลิกการ์ด Pick | หน้ารายการงานหยิบ | เข้าไปจัดการงานหยิบตาม operation type ที่เกี่ยวข้อง |
| คลิก Delivery Orders | หน้ารายการ Deliveries | ดูและประมวลผลการส่งของ |

## 2. Inventory Module

### 2.1 การจัดการคลังสินค้า (IV-05)

เส้นทางเข้าเมนู: Inventory > Configuration > Warehouses

หน้าจอนี้ใช้เก็บ master ข้อมูลคลัง เช่น ชื่อคลัง, stock location หลัก และที่อยู่ของคลัง เพื่อเป็นฐานให้ operation type และ location ภายในคลังทำงานได้ถูกต้อง

![รูปที่ 2.1 หน้าจอรายการคลังสินค้า](iv05_warehouses.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| New | สร้างข้อมูลคลังใหม่ | ได้ | เปิดฟอร์มสร้างคลังใหม่ |
| Search | ค้นหาคลังตามชื่อหรือข้อมูลที่เกี่ยวข้อง | ได้ | กรองรายการคลังที่แสดงบนหน้าจอ |
| Warehouse | ชื่อคลังสินค้า | ดู/กดได้ | กดเพื่อเปิดรายละเอียดคลัง |
| Location Stock | ตำแหน่ง stock หลักของคลัง | ดู/กดได้ | ใช้เป็นจุดอ้างอิงของสต็อกภายในคลัง |
| Address | ที่อยู่ของคลัง | ดู/กดได้ | ใช้แยกสาขาหรือสถานที่ทางกายภาพของคลัง |
| Pager | ตัวเลื่อนหน้า | ได้ | เลื่อนดูคลังรายการถัดไป |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| คลิก New | ฟอร์ม Warehouse | เพิ่มข้อมูลคลังใหม่ |
| คลิกชื่อ Warehouse | รายละเอียดคลัง | ดู operation type และ location ที่ผูกกับคลัง |
| ค้นหาคลังด้วย Search | หน้าเดิม | ช่วยกรองรายการคลังที่ต้องการ |

### 2.2 การจัดการสถานที่สินค้าคงคลัง (IV-06)

เส้นทางเข้าเมนู: Inventory > Configuration > Locations

Locations เป็นโครงสร้างสถานที่เก็บสินค้าในระบบ เช่น stock, hold, production, vendor หรือ customer location หน้านี้ใช้ดูและปรับข้อมูลสถานที่คงคลังที่เชื่อมกับทุก movement ของสต็อก

![รูปที่ 2.2 หน้าจอรายการ Locations](iv06_locations.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| New | สร้าง location ใหม่ | ได้ | เปิดฟอร์มสร้าง location |
| Search | ค้นหา location | ได้ | กรอง location ตามชื่อหรือเงื่อนไข |
| Location Name | ชื่อสถานที่เก็บสินค้า | ดู/กดได้ | กดเพื่อเปิดรายละเอียด location |
| Parent Location | location แม่ที่ location นี้อยู่ภายใต้ | ดู/กดได้ | ใช้กำหนดโครงสร้างลำดับชั้น |
| Location Type / Usage | ประเภทของสถานที่ เช่น Internal, Vendor, Customer | ดู/กดได้ | มีผลต่อ logic การเคลื่อนไหวสต็อก |
| Company | บริษัทที่ location นี้สังกัด | ดู/กดได้ | ใช้แยกข้อมูลตามบริษัท |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| คลิก New | ฟอร์ม Location | สร้าง location ใหม่ในโครงสร้างคลัง |

### 2.18 รายงานคุมสต็อกสินค้า (IV-22)

เส้นทางเข้าเมนู: Inventory > Reporting > Stock

รายงาน Stock ใช้ดูปริมาณสินค้าในแต่ละ location ในมุมมองภาพรวม ผู้ใช้ใช้รายงานนี้เพื่อตรวจสอบยอด on hand และเจาะลึกไปยัง movement หรือ location ที่เกี่ยวข้อง

![รูปที่ 2.18 หน้าจอรายงาน Stock](iv22_stock_report.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| Search | ค้นหาสินค้าหรือ location | ได้ | กรองข้อมูลในรายงาน |
| Product | ชื่อสินค้าที่แสดงในรายงาน | ดู/กดได้ | กดเพื่อเจาะลึกข้อมูลสินค้า |
| Location | สถานที่เก็บสินค้า | ดู | บอกว่าสินค้าอยู่ที่ใด |
| On Hand | ยอดคงเหลือจริง | ดู | ใช้ตรวจยอด stock ที่มีอยู่ |
| Forecast | ยอดคาดการณ์ | ดู | ใช้ดูผลกระทบหลังรวม incoming/outgoing |
| UoM | หน่วยนับ | ดู | ใช้ตีความปริมาณในรายงาน |
| Filter / Group By | เครื่องมือจัดมุมมองรายงาน | ได้ | เปลี่ยนเงื่อนไขการวิเคราะห์รายงานได้ |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| ใช้ Search | หน้าเดิม | กรองรายงานตามสินค้า, lot หรือ location |
| คลิก Product | ข้อมูลสินค้า / รายงานย่อย | เจาะลึกคงเหลือของสินค้านั้น |
| ปรับ Filter หรือ Group By | หน้าเดิม | เปลี่ยนมุมมองการวิเคราะห์ stock report |

### 2.19 รายงานคุมสต็อกสินค้า (IV-23)

เส้นทางเข้าเมนู: Inventory > Reporting > Moves History

Moves History เป็นรายงานประวัติการเคลื่อนไหวสินค้าแบบละเอียด ใช้ตรวจสอบย้อนหลังว่ามี stock move อะไรเกิดขึ้น เมื่อไร และย้ายจาก location ไหนไป location ไหน

![รูปที่ 2.19 หน้าจอ Moves History](iv23_moves_history.png)

ตารางอธิบาย field / คอลัมน์ที่เห็นบนหน้า

| Field / คอลัมน์ | คำอธิบาย | แก้ไขได้หรือไม่ | เมื่อกดหรือเปลี่ยนค่าแล้วเกิดอะไรขึ้น |
| --- | --- | --- | --- |
| Date | วันที่ของการเคลื่อนไหว | ดู | ใช้เรียง timeline การเคลื่อนไหวสินค้า |
| Reference | เลขอ้างอิงของ movement | ดู/กดได้ | กดเพื่อโยงกลับเอกสารต้นทาง |
| Product | สินค้าใน movement | ดู | ใช้ระบุว่าการเคลื่อนไหวเกิดกับสินค้าใด |
| Lot/Serial Number | เลข lot/serial ของสินค้าที่เคลื่อนไหว | ดู | ช่วย trace สินค้าแบบละเอียด |
| From | location ต้นทาง | ดู | บอกว่าของออกจากจุดใด |
| To | location ปลายทาง | ดู | บอกว่าของไปจุดใด |
| Quantity | จำนวนที่เคลื่อนไหว | ดู | ใช้วิเคราะห์ปริมาณที่รับเข้า/จ่ายออก |
| Status | สถานะ movement | ดู | ใช้ตรวจว่ารายการเสร็จสิ้นแล้วหรือยัง |

ตารางอธิบายการกดใช้งาน

| สิ่งที่ผู้ใช้กด | ไปหน้าจอไหนต่อ | ผลที่เกิดขึ้น |
| --- | --- | --- |
| คลิก Reference | เอกสารต้นทาง | เปิด receipt, delivery, internal transfer หรือ MO ที่เกี่ยวข้อง |
| ค้นหาด้วย Product หรือ Lot | หน้าเดิม | ใช้ trace ย้อนหลังแบบราย lot ได้ |
| เรียงตาม Date | หน้าเดิม | ดู timeline การเคลื่อนไหวสินค้าแบบต่อเนื่อง |
