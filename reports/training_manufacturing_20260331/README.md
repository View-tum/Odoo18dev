# Manufacturing Training Pack

Training pack นี้ออกแบบสำหรับ session `1 วัน / 3 ชั่วโมง` ของทีม Manufacturing โดยอิง flow และตัวอย่างเอกสารจริงจาก `DB 11`

ไฟล์ในชุดนี้
- `00_agenda.md` ตารางเวลา 3 ชั่วโมง
- `01_slide_outline.md` โครงสไลด์พร้อมหัวข้อและสาระหลัก
- `02_speaker_notes.md` script คนสอนแบบพูดตามได้
- `03_handout.md` handout สำหรับแจกผู้เข้าอบรม

ตัวอย่างเอกสารจริงที่ใช้ demo
- Promotion quote: `S11563`
- FOC flow: `SOB-263069`, `GMP/PICK/03571`, `GMP/OUT/02504`, `INV-D/26/03/00960`
- MTO flow: `SOB-263070`, `GMP/PICK/03572`, `GMP/OUT/02505`, `INV-D/26/03/00961`
- MTS flow: `GMP/MOPH/00011`
- 100000 production trace: `GMP/MOPH/00001`
- Mold and shopfloor: `GMP/MOPL/00014`, `SP/00011`
- Multi-level example: `FG-PSS-TH-01005`

กลุ่มผู้เข้าอบรมที่แนะนำ
- Production Planner
- Production Supervisor
- Shopfloor Leader
- Warehouse
- Purchase
- Accounting Key User
- IT / Odoo Key User

เป้าหมายหลังจบ session
- แยก `Promotion`, `MTO`, `MTS / Min-Max` ได้
- รู้ว่าอะไร `auto` และอะไรไม่ใช่
- trace เอกสาร `SO -> MO -> Transfer -> Delivery -> Accounting` ได้
- ใช้ `Shopfloor + Mold + Scrap` ได้
- รู้ว่าถ้า flow ไม่เดิน ต้องเช็ก setting ตรงไหนก่อน
