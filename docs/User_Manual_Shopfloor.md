# คู่มือการใช้งาน GMP Shopfloor (สำหรับพนักงานฝ่ายผลิต)

คู่มือนี้จะพาคุณทำความเข้าใจการใช้งานหน้าจอ **GMP Shopfloor** ทีละขั้นตอน (Step-by-Step) เพื่อให้การบันทึกงานผลิต การเบิกวัตถุดิบ และการแจ้งของเสีย ทำได้ง่ายและรวดเร็วที่สุดในหน้าจอเดียว!

## 1. การเข้าสู่ระบบและเริ่มงาน
หน้าจอ Shopfloor ออกแบบมาให้คุณเห็นเฉพาะงานของตัวเอง เพื่อไม่ให้สับสน

**ขั้นตอน:**
1. ไปที่เมนู **Manufacturing** > เลือกแถบ **Shopfloor** ด้านบน
2. ระบบจะแสดง "การ์ดงาน (Workorder)" ที่รอให้คุณผลิต
3. เมื่อพร้อมเริ่มงาน ให้กดปุ่ม **[เริ่มงาน / Start]** (ปุ่มสีเขียว) บนการ์ดใบนั้น
   - *สิ่งที่เกิดขึ้น:* นาฬิกาจับเวลาจะเริ่มเดิน เพื่อบันทึกเวลาทำงานจริงของคุณ และสถานะของใบสั่งผลิต (MO) จะถูกเปลี่ยนเป็น "In Progress"

---

## 2. การบันทึกผลผลิต (ได้ของดี)
คุณไม่ต้องรอให้จบสัปดาห์ค่อยมากรอกทีเดียว สามารถทยอยกรอกยอดของที่ทำเสร็จในแต่ละวันได้เลย

**ขั้นตอน:**
1. บนการ์ดงานที่กำลังทำอยู่ จะมีปุ่ม **[บันทึกยอด / Quick Done]** 
2. กดปุ่มแล้วใส่ "จำนวนสินค้าที่ผลิตได้ดี" ในรอบนั้น
3. กด **[ยืนยัน / Confirm]**
   - *สิ่งที่เกิดขึ้น:* ระบบจะบวกยอดเข้าเป็น "Console Qty" ให้ทันที
4. **ถ้าทำครบตามจำนวนที่สั่งแล้วล่ะ?**
   - ให้คุณกดปุ่ม **[เครื่องหมายถูก (Finish)]** ที่มุมการ์ด 
   - ระบบจะถามยืนยัน 1 ครั้ง 
   - พอกดยืนยัน การ์ดใบนี้จะกลายเป็นสีเทา (Done) แปลว่าจบหน้าที่ของคุณในงานนี้แล้ว

## 3. ของพังทำอย่างไร? (การแจ้ง Scrap)
ถ้าระหว่างทำ มีการทำ **"วัตถุดิบพัง"** (เช่น ฝาแตก, หลอดเบี้ยว) ไม่ต้องตกใจและไม่ต้องเดินไปหาสโตร์! ระบบจะจัดการเบิกของใหม่มาให้คุณเอง

**ขั้นตอน:**
1. บนการ์ดงานของคุณ ให้กดไอคอน **[ถังขยะ (Scrap)]**
2. หน้าต่างแจ้งของเสียจะเด้งขึ้นมา 
3. เลือก **ชื่อวัตถุดิบ** ที่พัง (ระบบจะแสดงเฉพาะของที่อยู่ในบิลนี้เท่านั้น)
4. ใส่ **จำนวน** ที่พัง
5. ใส่ **เหตุผล** สั้นๆ (เช่น ประกอบพลาด, ของมาบิ่น)
6. กดปุ่ม **[บันทึก (Save)]**

**🔮 สิ่งที่ระบบแอบทำให้คุณเบื้องหลัง (Magic):**
- ถ้ายอดที่คุณใส่ "เกินกว่าจำนวนที่สั่งมา" ระบบจะเตือนสีเหลือง และไม่ให้กด Save
- ถ้ายอดถูกต้อง **ระบบจะวิ่งไปเช็คของที่หน้างานให้ทันที:**
  - **ถ้าหน้างานมีของเหลือ:** ระบบจะตัดสต็อกให้เลย คุณหยิบของที่เหลือมาทำต่อได้ทันที
  - **ถ้าหน้างานของหมด:** ระบบจะสั่งให้ สโตร์ (Warehouse) จัดเบิกของใส่กล่องมาส่งให้คุณที่หน้าโต๊ะทำงาน (คุณทำงานอื่นรอได้เลย)

## 4. วัตถุดิบไม่พอเบิกเพิ่มอย่างไร? (การรับของ)
กรณีที่ระบบสั่งเบิกของให้คุณจากข้อ 3 (หรือคุณสั่งเบิกเพิ่มเอง) คุณสามารถดูคิวของที่กำลังมาส่งได้

**ขั้นตอน:**
1. สังเกตที่ปุ่มเมนูด้านขวามือบน จะมีไอคอน **[รถบรรทุก (Pickings)]**
2. กดเข้าไปเพื่อเปิดแผงสไลด์ (Drawer) แผงนี้จะโชว์ "ใบเบิกวัตถุดิบ" ทั้งหมดที่เกี่ยวข้องกับงานของคุณ
3. เมื่อสโตร์นำของมาส่งถึงโต๊ะ คุณสามารถตรวจสอบจำนวน 
4. กดปุ่ม **[ยืนยันรับของ (Validate)]** จากหน้านี้ได้เลย โดยไม่ต้องสลับจอหนี
   - *สิ่งที่เกิดขึ้น:* ของจะถูกย้ายเข้าคลังหน้าโต๊ะคุณ พร้อมให้คุณหยิบไปผลิตทันที

## 5. การปิดงานสิ้นวัน/สัปดาห์
โรงงานเราเปิดบิลแบบรายสัปดาห์ ดังนั้นพนักงานประกอบคนสุดท้าย หรือหัวหน้ากะ จะเป็นคนกดปิดบิลรวม

**ขั้นตอน:**
1. มองหาปุ่ม **[Apply Console / Close Production]** ที่มุมขวาบนของหน้าจอ
2. กดปุ่มนี้เมื่อต้องการสรุปยอดส่งของเข้าโกดัง 
3. **สิ่งที่ระบบจะจัดการให้:**
   - ถ้ายอดรวม "ขาดไป" (เช่น สั่งทำ 1000 แต่ทำได้ 800) ระบบจะปิดยอดที่ทำเสร็จเข้าคลัง และสร้าง **Backorder (ใบค้างผลิต)** สำหรับ 200 ชิ้นที่เหลือให้อัตโนมัติในสัปดาห์ถัดไป
   - ระบบจะหักล้างวัตถุดิบ รวมถึงของเสีย (Scrap) ที่คุณกดทิ้งไว้ระหว่างวันให้อย่างถูกต้องตามหลักบัญชี

> 💡 **เคล็ดลับ:** หากคุณลืมกดตรวจสอบคุณภาพ (QC) ระบบจะไม่ยอมให้ปิดงาน ให้กลับไปกดตรวจสอบคุณภาพก่อน!
